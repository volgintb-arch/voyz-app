# План работ

## MVP (3–4 недели на Claude Code + 1 разработчик-ревьюер)
1. Каркас Expo (TypeScript, expo-router), темы и токены, шрифт Mulish, логотип SVG.
2. Данные: загрузка `places.json` из ассетов, сторы (zustand + MMKV): страна, избранное, маршрут.
3. Обзор, поиск, фильтры, «Все места».
4. Карточка места со всеми блоками из UX-спецификации, shared element, параллакс, компактная шапка со scroll-spy.
5. Карта маршрута в карточке и вкладка «Карта» (MapLibre RN, стиль по токенам, источники GeoJSON из `geo.json`). Прорисовка линии.
6. Вкладка «Маршрут»: Дейкстра на графе (порт из `prototype_src/app.js → roadRoute`), дни, drag & drop.
7. Deep links в Яндекс, 2ГИС, Google и geo:, звонки tel:.
8. Аудиогид: expo-speech (TTS, ru-RU) → позже mp3.
9. EAS Build: iOS (TestFlight) и Android (Internal testing).

## v1
- Офлайн-пакеты карт по стране (MapLibre offline + PMTiles/OSM), загрузка полных фото с прогрессом.
- Бэкенд: отметки «Заметили изменения?», отзывы с фото и модерацией, версия датасета.
- Каталог туров Voyz в «Хочешь сюда?» (маркетплейс).
- Аналитика (AppMetrica уже используется в Voyz): события `place_open`, `route_variant_select`, `nav_open{provider}`, `save`, `trip_add`, `audio_play`, `change_report`, `filter_apply`.
- Push: «Перевал открылся», «Сезон начинается».

## v2
- Настоящие GPX-треки троп и профиль высот, навигация по треку офлайн.
- Записанные аудиогиды, локализация EN и KY.
- Расширение географии (Казахстан, Узбекистан, остальной Алтай).

## Аудиогид — статус
Озвучено 112 гидов нейроголосом «Дмитрий» (Microsoft Edge TTS, ~79 минут, файлы `audio/<id>.mp3`). MP3 в пакет не вложены из-за размера; они есть в `voyz-prototype-site.zip` и в `voyz_audio.zip`. Длительности лежат в `prototype/data/audio.js`. Для коммерческого релиза нужна лицензированная озвучка (ElevenLabs через OpenRouter — около $2,6 за весь объём, или диктор). Плеер: `expo-audio`; фоновое воспроизведение и экран блокировки — через `expo-audio`/`react-native-track-player`.
