# UX-спецификация приложения Voyz (iOS + Android)

Эталон поведения — веб-прототип в `prototype/` (откройте `prototype/index.html` через любой статический сервер). Эталон вида карточки места — `design/reference/voyz_place_card_mockup.jpg` и кадры видео `voyz_scroll_video_frames_*.png`.

## Информационная архитектура
```
Splash (логотип собирается по буквам, 1.5 с)
└─ Онбординг (только первый запуск): «Куда едем?» → Кыргызстан | Россия · Алтай
   └─ Таб-бар (плавающая чёрная «пилюля», лаймовый индикатор)
      ├─ Обзор        — подборки, категории, поиск, фильтры, все места
      ├─ Карта        — полноэкранная карта, маркеры, карусель превью снизу
      ├─ Маршрут      — «Маршрут» (поездка по дням) | «Избранное»
      └─ Ещё          — страна, офлайн, «Как мы проверяем», предложить место
   Поверх любого таба — стек «Карточка места» (push), шторки (bottom sheet), просмотрщик фото
```

## Экраны

### 1. Обзор
- **Чёрная шапка:** логотип VOYZ, переключатель страны (сегмент с лаймовым «ползунком» на пружине), заголовок «КУДА ПОЕДЕМ В <МЕСЯЦЕ>?», счётчик мест, поиск с кнопкой фильтров.
- **Белый лист** с радиусом 34 наезжает на шапку (−34 px).
- Подборки по порядку:
  1. «Хорошо в <месяце>» — карусель больших карточек 250×330; места, где текущий месяц входит в `m`.
  2. Чипсы категорий, сгруппированных функцией `catShort`.
  3. «Лучше всего изучено» — топ-5 по `idx` в виде `rowCard` с кольцом индекса.
  4. «Можно без машины» — есть транспорт: маршрутка, автобус, поезд, катер.
  5. «Недалеко от Бишкека / Горно-Алтайска» — до 170 км по прямой.
  6. «Все места» — сетка 2 колонки, у каждой карточки сердечко.
- **Поиск** по `name, full, cat, reg, dist, near, short`, задержка 160 мс. Результаты заменяют подборки; активные фильтры показаны чипсами с крестиком.
- **Шторка фильтров:** месяц, категория, сложность, доступ, «есть маршрутка», «только с фото». Кнопка показывает живой счётчик: «Показать 23».

### 2. Карточка места (главный экран, по макету)
Порядок блоков (id якорей для навигации в скобках):
1. **Hero 540 px:** листаемые фото, паралакс ×0.35 при скролле, градиент в чёрный. Кнопки «стекло» (blur): назад, поделиться, сердце. Плашка рейтинга («4.8 ★ Google» — только реальный рейтинг из `reviews`, иначе «✓ Проверено»), точки галереи, заголовок КАПСОМ, локация, мини-карта 62×62 справа (по тапу — к маршруту). Если фото нет, hero — карта места.
2. **Сетка 2×2** в чёрной рамке с градиентом: Сложность, Когда, Доступ (иконка зависит от типа: машина, 4×4, пешком, по воде), Время на месте (или Вход).
3. **«Почему стоит приехать» (ov)** — текст `guide` на чёрном фоне, свёрнут до ~250 px.
4. **Белый лист** (радиус 34, наезжает на чёрное, как в видео):
   - Аудиобар «Послушать VOYZ-гид» с длительностью. В прототипе озвучка через TTS, в приложении — записанное аудио с фолбэком на TTS.
   - **Медиа:** большая плитка и две маленькие, «+N»; видео — плитка с ▶ и превью YouTube; ссылки на видео; «Смотреть все» открывает просмотрщик с автором и лицензией.
   - **Как добраться (route):** краткая сводка, горизонтальный выбор вариантов подъезда (бейдж «Рекомендуем»). Ниже **карта маршрута**: белая обводка и чёрная линия по трассе (анимация прорисовки 1.6 с), пунктир — подъезд, точки — тропа; маркеры S (старт), P (парковка), ★ (место, пульсирует); лаймовая FAB «+» добавляет в маршрут (поворот на 45°, когда добавлено); легенда. Под картой — чипсы (время, км, машина), **таймлайн шагов** (Старт → Дорога → Последние АЗС → Парковка → Начало тропы → Место), плашка опасностей, кнопки «Яндекс Карты / 2ГИС / Google Maps / Другое приложение» с координатой парковки, источник.
   - **Транспорт и перевозчики** — горизонтальные карточки (иконка вида транспорта, перевозчик, откуда, цена, «Связаться» = tel:, «Сайт» или «Источник»).
   - **Подробнее о месте** — описание, что посмотреть, «можно пропустить, если», высота.
   - **Хочешь сюда?** — «Туры и трансферы» (шторка с турами из `transport`, где mode = тур/экскурсия/трансфер; в проде — каталог Voyz) и «Добавить в маршрут».
   - **Когда ехать:** полоса из 12 месяцев (лайм — сезон, рамка — текущий месяц), текст сезона, лучшее время суток, режим работы.
   - **Лучше взять с собой** — чипсы с иконками из поля `bring`.
   - **Важно (imp)** — оливковая карточка: предупреждения и разрешения.
   - **Где остановиться (stay)** — карусель `stays`.
   - **Что попробовать** — карусель `food`.
   - **На месте (site):** тропы (км, набор, время, сложность), верхом, чем заняться, прокат, сетка инфраструктуры (туалет, вода, магазин, банкомат, АЗС, связь, медицина, спасатели), доступность.
   - **Бюджет** (эконом / комфорт), **Готовые планы** (`iti`), **Рядом** (4 места с км; «Показать на карте»).
   - **Что говорят путешественники** — плашки рейтингов площадок и сводка отзывов. Отзывы не придумываем; пользовательские отзывы — после запуска бэкенда.
   - **Проверка и источники (src):** кольцо индекса (анимация 1.2 с при появлении), полосы «подтверждено X/34», «насыщенность», «практика», дата проверки, спорные моменты, «пока не подтверждено», список источников.
   - **Заметили изменения?** — лаймовая карточка, чипсы, «Отправить» (в проде — POST в модерацию, офлайн-очередь).
   - Футер с логотипом.
- **Компактная шапка** появляется, когда hero уходит за экран: назад, название, сердце и ряд чипсов-якорей (Обзор / Как добраться / Ночлег и еда / На месте / Важно / Проверка) со scroll-spy. Над чёрным шапка тёмная, над белым — светлая; статус-бар меняет цвет вместе с ней.

### 3. Карта
Полноэкранная офлайн-карта. Сверху поиск и чипсы категорий, справа кнопки «показать всё», «где я», «онлайн-слой». Снизу горизонтальная карусель превью: синхронизирована с маркерами (тап по маркеру прокручивает карусель, остановка карусели подсвечивает маркер и сдвигает к нему карту). Повторный тап по активной карточке открывает место. Маркеры уменьшаются на мелком масштабе; места из TOP окрашены инверсно.

### 4. Маршрут
- Сегмент «Маршрут | Избранное».
- **Маршрут:** карта с линиями по дорогам (Дейкстра на графе `geo.json`), сводка (мест, км по дорогам, дней), оценка часов за рулём (средняя 52 км/ч). Разбивка по дням — порог 6.5 ч в день с учётом ~1.5 ч на каждое место. Остановки можно двигать вверх и вниз (в RN — drag & drop), есть «Оптимизировать» (ближайший сосед) и «Очистить». Пустое состояние предлагает кнопку «Собрать пример».
- **Избранное:** список с кнопкой «+ В маршрут».

### 5. Ещё
Смена страны, «Работает без интернета», «Как мы проверяем места», «Карта без сети», «Показать приветствие снова», «Предложить место».

## Анимации и жесты (обязательные)
| Момент | Поведение |
|---|---|
| Открытие карточки из списка | Shared element: фото летит из карточки в hero (480 мс), фон плавно проявляется |
| Push / pop | Слайд справа, предыдущий экран уезжает на −22 % и затемняется; свайп от левого края назад; на Android — системная кнопка «назад» |
| Hero | Параллакс и лёгкое увеличение при скролле, листание фото со snap и точками |
| Чёрное → белое | Белый лист с радиусом наезжает на чёрный блок (см. видео) |
| Сердце | Pop ×1.28 на пружине, тактильный отклик, тост «Сохранили в избранное» |
| Таб-бар | Лаймовый индикатор переезжает на пружине; таб-бар прячется вниз, когда открыта карточка |
| Маршрут | Прорисовка линии (stroke-dashoffset) после подгонки границ; при смене варианта — плавная смена текста и новая линия |
| Кольцо и полосы индекса | Заполняются при появлении в зоне видимости |
| Аудиобар | Эквалайзер из 4 полосок, прогресс по границам слов |
| Шторки | Выезжают снизу и закрываются свайпом вниз |
| Reduced motion | Всё упрощается до crossfade |

## Доступность
Контраст текста не ниже AA (лайм используем только как фон под чёрным текстом), размер нажимаемой зоны не меньше 44×44, у кнопок-иконок есть подписи для VoiceOver и TalkBack, поддержка Dynamic Type до XL (заголовки КАПСОМ переносятся), видимый фокус.

## Офлайн
- Данные (`places.json`), миниатюры и граф дорог входят в сборку.
- Большие фото скачиваются по стране кнопкой «Скачать Кыргызстан / Алтай» с прогрессом.
- Базовая карта в MVP — встроенная векторная схема (Natural Earth). В v1 — офлайн-пакет MapLibre (OSM/PMTiles) по стране.
- Отметки «Заметили изменения?» и сохранения копятся в очереди и синхронизируются, когда появляется сеть.

## Читаемость (v2)
- На странице места показываем только **короткие версии** текстов: 1–3 предложения. Полный текст открывается в **ридере** — шторке на 92 % высоты, кегль 17/1.62, подзаголовки и списки.
- Блок **«Главное»** сразу под аудиогидом: до 6 строк «иконка — метка — одна фраза» (дорога, вход, лучшее время, связь, ночлег, осторожно).
- **Числа с единицами** (км, ч, мин, сом, ₽, °C, %) выделяются жирным: их видно при беглом просмотре.
- Шаги маршрута обрезаны до 3 строк, раскрываются по тапу («ещё»).
- «Важно» — первые 3 пункта, остальное в ридере.
- Второстепенное (подробнее о месте, чем заняться, верхом, прокат, инфраструктура, бюджет, планы, доступность, отзывы) собрано в сгруппированный список **«Полезное»** в стиле iOS inset grouped: строка — иконка, заголовок, превью в одну строку, шеврон. Тап открывает ридер.
- Источники и спорные моменты тоже вынесены в ридер, на странице остаётся только кольцо индекса и полосы.
