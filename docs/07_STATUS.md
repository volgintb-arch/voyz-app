## Сверх плана (по запросу)
- **Мини-фото вместо точек** на карте и группировка (supercluster) с числом мест.
- **Зум кнопками, компас**, поворот и наклон жестами.
- **Слои:** «Схема» (офлайн) / «Подробная» (OpenFreeMap, онлайн), **тени гор** (Terrain Tiles), **3D-наклон** (объём — в вебе; на телефоне — наклон камеры).
- **Онлайн-маршрут «от меня»** (OSRM) и **ведение**: плашка манёвра, голосовые подсказки, пересчёт при съезде.
- **«Я здесь был» и карта путешествий:** отметка в карточке (с датой, офлайн), галочка на мини-фото,
  раздел «Был» во вкладке «Маршрут» — **карта мира** (Natural Earth 1:110m, `assets/data/world.json`, `tools/build-world.mjs`):
  страны отмечаются тапом по карте или поиском, приближение по континентам, Кыргызстан / Россия отмечаются сами по местам Voyz;
  цифры — страны из 195, % мира, континенты, места Voyz; **постер для соцсетей** (весь мир, флаги, PNG через «Поделиться»).

## Доведено после MVP
- **Рельеф без сети** на всех картах: отмывка гор (Terrain Tiles z8, метод Хорна) встроена картинкой на страну.
- **Веб-версия** https://volgintb-arch.github.io/voyz-app/ — без входа, обновляется при каждом пуше; на компьютере — колонка ширины телефона.
- **Доступность:** вторичный текст #6E6E6A (контраст 5.1:1, AA), чипсы и кнопки растут при крупном шрифте, таб-бар ограничен.
- **Иконка и сплэш Voyz** (tools/build-icons.mjs): лаймовая V на чёрном, слово VOYZ на сплэше.

- **Английская версия интерфейса** (v1): RU / EN на первом экране и во «Ещё», по умолчанию — язык телефона. Переведены все подписи, фильтры, короткие значения данных (сложность, доступ, сезон, регион, категории), ридеры, голос и манёвры навигации. **Описания всех 112 мест переведены** (черновой перевод ИИ по глоссарию `translations/GLOSSARY.md`): тексты лежат в `translations/en/<id>.json`, собираются `node tools/i18n-build.mjs` в `assets/data/places.en.json` и накладываются поверх русских данных; поля-ключи логики (категория, регион, сезоны, фильтры) не переводятся. В карточке пометка «Translated by AI — not yet reviewed by an editor»; редактор, проверив место, добавляет id в `translations/en/_reviewed.json` — пометка исчезает. В английском интерфейсе аудиогид читает английский текст синтезом речи (запись есть только русская).
- **Отзывы путешественников:** блок в карточке и форма «Оставить отзыв» (оценка, текст от 20 знаков, имя по желанию). Отзыв сохраняется на телефоне и уходит на модерацию, когда подключён сервер и есть сеть; показываются только одобренные + свой со статусом. Пока сервера нет — только свои (фейковых не рисуем).
- **Веб-версия как приложение (PWA):** установка на главный экран, «Сохранить для офлайна», ссылки на места, превью для мессенджеров.

## Отличия от прототипа
- **Shared element** (фото «летит» в hero) — своя реализация (`src/lib/photo-flight.ts`, `components/place/photo-flight.tsx`) вместо экспериментальных shared transitions Reanimated 4: карточка запоминает место фото, экран места растягивает его в hero за 480 мс. Работает в iOS, Android и вебе; при «Уменьшить движение» — кроссфейд. Обратный полёт (назад) не делаем.
- **Шторки** — своя реализация (Modal + Reanimated) вместо @gorhom/bottom-sheet: одинаково работает на iOS, Android и в вебе, Android «назад» закрывает шторку.
- **Онлайн-слой** — OpenFreeMap вместо тайлов openstreetmap.org: правила OSM запрещают нагрузку от приложений.
- **Маршрут хранится плоским списком**, дни считаются автоматически (как в прототипе); сохранения v1 мигрируются.
- **Вторичный текст темнее макета** (#6E6E6A вместо #8C8C88) — ради контраста AA.
- **Миниатюры:** для 138 фото без `t_…` сделаны свои (`tools/build-thumbs.mjs`, 420 px) — у всех 446 фото в списках лёгкая версия.
