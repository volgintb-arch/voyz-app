# База мест в Excel

`data/voyz-places.xlsx` — рабочая база мест для редакции: **одна карточка — один лист**. Из неё собирается `assets/data/places.json` и английские тексты.

## Листы
| Лист | Что это |
|---|---|
| `README` | инструкция для менеджера |
| `Оглавление` | все карточки со ссылками; название/страна/статус подтягиваются формулами из карточек; сводка справа |
| `kg-…`, `alt-…` | карточка места; имя листа = id |
| `_шаблон` | пустая карточка — копировать для нового места |
| `Теги` | словарь тегов (id, RU, EN, группа) |
| `Тикеты` | задачи редакции: тип, карточка, статус, приоритет, исполнитель, сроки |
| `Справочники` | значения выпадающих списков |

## Карточка
Разделы в порядке экрана места: Основное → Коротко на карточке → Обзор → Медиа → Дорога → Сезон и что взять → Важно → Ночлег и еда → На месте → Сервисы → Бюджет → Что говорят → Рядом → Проверка → Перевод EN.

Разметка для парсера (колонка A):
- ключ поля (`name`, `short`, …) → значение в колонке C;
- `#section` — заголовок раздела; `#title` — шапка листа;
- `#table:<имя>` → `#keys` (ключи колонок, начиная с C) → `#labels` → строки данных с пустой A; номер записи — колонка B (`pos`); пустые строки пропускаются; таблица кончается на следующей строке с непустой A.

Таблицы: `photos`, `videos`, `photo_links`, `routes`, `transport`, `stays`, `food`, `hikes`, `horses`, `activities`, `rent`, `itinerary`, `nearby`, `fixes`, `sources`, `sources_practical`, `translations_en`.

## Коды карточки
Слова на плашках не пишутся вручную — приложение берёт их из справочника по коду (src/data/codes.ts, лист «Справочники»):

| Поле в Excel | Код в данных | Значения |
|---|---|---|
| Сложность — код | `content.difficulty` | 1 Очень лёгкая · 2 Лёгкая · 3 Средняя · 4 Сложная · 5 Очень сложная |
| Доступ — код | `content.access` | any-car · crossover · 4x4 · on-foot · by-water |
| Группа категории — код | `content.category` | lakes, waterfalls, canyons, gorges, passes, valleys, mountains, parks, springs, culture, caves, other |
| Связь на месте — код | `content.net` | yes · partial · no · unknown |

«Категория (подробно)» остаётся подписью на карточке. «Когда (коротко)» больше нет — подпись сезона приложение строит из «Месяцев сезона» («Июн – сен», «Круглый год»).
«Вход (коротко)» и «Время на месте (коротко)» — короткий текст без «…» (до ~26 знаков): «Бесплатно», «50 сом с человека», «1–2 ч», «Полдня». Английский «Входа» — в переводе карточки.

## Оценка месяцев
Поле «Оценка месяцев» в разделе «Коротко на карточке» — JSON вида `{"6":1,"7":2,"8":2}`: 2 — лучшее время, 1 — подходит, месяца нет — не сезон. Пусто — в приложении сезон по «Месяцам сезона» одним цветом. Импорт проверяет формат и предупреждает о месяцах вне сезона.

## Команды
| Команда | Что делает |
|---|---|
| `npm run places:export` | `places.json` + переводы → Excel (тикеты и теги из прежнего файла сохраняются) |
| `npm run places:check` | проверки: обязательные поля, имя листа = id, координаты, месяцы, файлы фото, теги |
| `npm run places:import` | Excel → `places.json` + `translations/en/*.json` + `_reviewed.json`, затем сборка перевода |

В приложение попадают только карточки с «Публикация = опубликовано». После импорта с новыми фото — `npm run gen:media`; если менялись русские тексты — `node tools/i18n-extract.mjs`.

Код: формат листов — `tools/places_cards.py`, схема полей и проверки — `tools/places_xlsx.py`.
Проверка без потерь: `python tools/places_cards.py roundtrip` (выгрузка → загрузка → сравнение с `places.json`; сейчас 0 отличий).
