# Скрипты генерации данных

- `geo_build.py` — скачивает слои Natural Earth (дороги, реки, озёра, границы), обрезает их по регионам и строит граф дорог → `geo.json`.
- `export.py` — собирает `places.json` из исходного каталога Voyz: нормализует поля, разбирает сезон по месяцам, строит маршруты «город → парковка» по графу дорог, пережимает фото.
- `build_app.py` — собирает веб-прототип из `prototype_src/`.

Пути в скриптах абсолютные — из рабочей среды, где они запускались. Перед повторным запуском поправьте их под себя.
